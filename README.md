FinTech Loan Affordability Calculator

A simple web-based loan affordability calculator built using HTML, CSS, and JavaScript.

Features

- Calculates disposable income
- Calculates estimated monthly EMI
- Calculates remaining income after EMI
- Calculates EMI-to-income ratio
- Provides loan affordability assessment
- Includes input validation

Technologies Used

- HTML
- CSS
- JavaScript
